## 模组简介

**袖里舆图（`aleeve_atlas`）** 是一款基于 NeoForge 1.21.11 的地图模组，兼具右上角小地图与全屏世界地图。除了基础的探图、标点和生物雷达外，它还主打**多人联机协同**——不仅能和队友实时共享探索过的地图与路径点，还能像射击游戏一样用鼠标中键快速“Ping”出临时标点，方便联机探险时给队友指路或报点。

* **单人 / 仅客户端安装**：可正常记录本地地图、管理路径点，进任何服务器都能用。
* **双端安装（客户端 + 服务端）**：额外解锁小队地图实时同步、路径点分享和多人快捷标点功能。

## 前置与安装

**基础环境**：Minecraft `1.21.11` + NeoForge `21.11.x`

本模组依赖 **AnvilLib 2.x**（`2.0.0` 及以上版本），该前置已内嵌，无需单独安装。

## 主要功能

* **可自定义小地图**：支持切换圆形或方形边框、视角旋转或锁定北向，以及自定义缩放级别；底部可显示当前坐标、生物群系、光照强度与游戏内时间。
* **全屏世界地图**：支持鼠标拖拽与滚轮缩放，可在地图上直接管理路径点或打开模组配置界面。
* **玩家指示器**：小地图和世界地图可分别独立选择带黑色描边的抗锯齿水滴图标或原版玩家图标（默认均为水滴图标）。小地图指示器随面板尺寸缩放，世界地图指示器保持固定屏幕尺寸；原版样式支持资源包替换。
* **独立地图缓存**：自动保存已探索地形。地图数据按存档、服务器及维度严格隔离，互不冲突。
* **生物与玩家雷达**：在小地图上显示周围的生物和玩家头像，支持按生物类别自定义显示规则。
* **路径点与死亡标记**：支持世界内光柱/图标显示、自动生成死亡路径点，并提供聊天指令以便导入或导出路径点数据。
* **原版地图旗帜导入**：手持已绘制的原版地图，在世界地图中点击“导入地图”，即可将地图上标记的旗帜保存为持久路径点，并保留其名称、底色与精确坐标。重复导入会保留个人修改；该功能在单人游戏或支持旗帜导入的服务端上可用。
* **快捷标点（轮盘）**：在世界内或全屏地图上点击鼠标中键即可打下临时标点。按住中键可呼出轮盘，在“前往”、“一般”、“警告”和“危险”四种标点间快速选择。
* **小队地图同步**：服务端安装模组后，同队玩家可自动合并已探索的地图区域，并支持一键分享路径点。
* **模组联动与 API**：原生预留了领地区块覆盖层与外部标点接口，方便其他模组接入。

## 默认按键

所有键盘按键绑定均可在 Minecraft 原生的「选项 -> 控制 -> 按键绑定」菜单中自定义：

| 按键 / 操作 | 功能说明 |
| --- | --- |
| `M` | 打开 / 关闭全屏世界地图 |
| `N` | 在脚下位置快速新建路径点 |
| `=` / `-` | 放大 / 缩小小地图显示范围 |
| 按住 `Z` | 临时将小地图居中并放大（松开按键后恢复原样，适合快速看路） |
| **短按** 鼠标中键 | 看着方块或地图短按中键，直接在目标处打一个“一般”临时标点 |
| **长按** 鼠标中键 | 呼出标点轮盘，拖动鼠标选择标点类型（危险/警告/一般/前往），松开中键即可发出 |

## 配置文件与数据目录

* **客户端配置**：可按 `M` 在世界地图界面内点击设置按钮直接修改，或编辑 `<游戏目录>/config/aleeve_atlas-client.toml`。
* **服务端配置**：位于 `<存档目录>/serverconfig/aleeve_atlas-server.toml`。
* **地图缓存与标点数据**：位于 `<游戏目录>/data/aleeve_atlas/`（其中 `mapdata` 文件夹存放已探索的地图文件，按存档/服务器及维度分文件夹存放，重装整合包时备份此目录即可保留地图）。

更多配置详情请参考 [配置与交互指南](docs/CONFIG.md)。
